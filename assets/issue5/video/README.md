## 画面と数値の照合

- キリドリ: `KiridoriApp/STATUS.md` にある現行の `kiridori_v60.html` をローカルで開き、定尺長6,000mm、刃幅5mm、部材2,500mm・1,800mm・1,200mmを各2本入力した状態と、その計算結果を撮影。結果画面の1本目は「2部材・2切断／残990mm」。動画の数値と一致する。
- ハリナビ: `HarinaviApp/STATUS.md` が指す現行の `harinavi_V26.09.062.html` をローカルで開き、スパン長3,000mm、吊り荷の質量2tで検算を実行。結果画面に表示された曲げ応力69.691N/mm²と入力条件を照合した。安全の最終判断は専門家が行う旨を全ハリナビ動画に小さく表示した。
- 全動画に「画面の数値は動作確認用の例です」を表示。紙メモ風の画面はアプリUIではなく説明素材として示した。架空のアプリ画面は作っていない。

## 再制作

`node assets/issue5/video/capture-source.cjs` で現行アプリの画面を取得し、`python assets/issue5/video/make_source_crops.py` で結果の実画面を切り出す。公式VOICEVOX Nemoを `127.0.0.1:50121` で起動し、`python assets/issue5/video/render-narrated-videos.py` で音声合成と動画の合成を行う。`python assets/issue5/video/make_contact_sheet.py` で一覧を更新する。再制作時は現行版と画面内の数値を再照合すること。`source/` は照合用の実画面、`frames/` は動画生成用フレーム。既存の `frames/*.txt` は初版の静止画連結記録で、今回の書き出しには使用しない。
